# טופס טיולים גדודי

אפליקציית Web בעברית לניהול חתימות קציני מטה לפני יציאת פלוגות הביתה. נבנתה באותו סגנון ובאותה תשתית כמו תיאומון.

* **שרת:** Node.js 20 ומעלה, ללא framework. מסד נתונים SQLite דרך libSQL: בפרודקשן **Turso** (חינם), מקומית קובץ.
* **לקוח:** HTML/CSS/JS ללא שלב בנייה, RTL, מותאם לטלפון ולמחשב, מצב כהה אוטומטי, אפשר להוסיף למסך הבית.
* **אבטחה:** כל ההרשאות נאכפות בשרת. סיסמאות בגיבוב scrypt, עוגיית HttpOnly + SameSite=Strict, הגנת CSRF, הגבלת ניסיונות התחברות.
* **עדכון חי:** חתימה או אישור מופיעים מיד אצל כל מי שהמסך שלו פתוח.

## איך זה עובד

| משתמש | מה הוא רואה ועושה |
|---|---|
| קצין מטה (11 תפקידים) | רשימת 10 הפלוגות עם ✓ חתמתי / ○ טרם חתמתי. בוחר פלוגה ולוחץ "אישור חתימה". חותם רק בשם התפקיד של החשבון. |
| משתמש פלוגתי (10 פלוגות) | רק הטופס של הפלוגה שלו בסבב הנוכחי: מי חתם, מתי, וסטטוס אישור המג״ד. צפייה בלבד. |
| מג״ד | פתיחת סבב, צפייה בכל הפלוגות, אישור סופי לכל פלוגה (רק אחרי 11/11), סיום סבב, ניהול משתמשים, היסטוריה. |

אין איפוס אוטומטי. המג״ד מסיים סבב (החתימות ננעלות לצפייה) ופותח סבב חדש נקי. הסבבים הקודמים נשמרים בהיסטוריה.

## הפעלה מקומית

```bash
npm install
npm start            # http://localhost:3100  (נתונים ב־data/tiyulim.db)
npm test             # בדיקת התהליך המלא
npm run seed-demo    # מקומי בלבד: משתמשי דמו לכל תפקיד ופלוגה
```

## המג״ד הראשון

* **באוויר (Render):** מגדירים `SETUP_CODE` (לפחות 12 תווים). במסך ההתחברות מופיע "הקמת מג״ד ראשון". מי שמזין את הקוד הופך למג״ד, ומאותו רגע הקוד לא עובד יותר.
* **בטרמינל:** `npm run create-admin -- <שם משתמש> "<שם מלא>"` (מדפיס סיסמה זמנית).

משם המג״ד יוצר את כל שאר המשתמשים בלשונית "משתמשים". שכחו סיסמה? המג״ד לוחץ "איפוס סיסמה" ומקבל סיסמה זמנית.

## העלאה לאוויר — Render + Turso (כמו תיאומון)

1. **Turso:** ב־turso.tech → Create Database בשם `tiyulim`, אזור Frankfurt. מעתיקים את ה־Database URL (`libsql://…`) ויוצרים Token עם הרשאת read & write.
2. **GitHub:** מאגר פרטי עם הקוד.
3. **Render:** New → Blueprint → בוחרים את המאגר. Render קורא את `render.yaml` ומבקש:
   `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN`, `SETUP_CODE`.
4. נכנסים לכתובת שהתקבלה, "הקמת מג״ד ראשון" עם הקוד, ויוצרים את המשתמשים.

כל `git push` ל־`main` עולה אוטומטית. הנתונים ב־Turso לא נפגעים.
בתוכנית החינמית Render מרדים את השרת אחרי 15 דקות ללא שימוש; הפתיחה הראשונה אחר כך לוקחת כחצי דקה עד דקה.
